# User Slash Command Shortcuts for PC Maintenance

If the user starts a message with any of these slash commands, immediately activate the `pc-toolbox` skill and run the corresponding action:

- `/toolbox` or `/all`: Run `cmd.exe /c "C:\Users\advdi\tools\Toolbox\toolbox.cmd All"`
- `/boost`: Run `cmd.exe /c "C:\Users\advdi\tools\Toolbox\toolbox.cmd BoostRAM"`
- `/clean`: Run `cmd.exe /c "C:\Users\advdi\tools\Toolbox\toolbox.cmd Clean"`
- `/status`: Run `cmd.exe /c "C:\Users\advdi\tools\Toolbox\toolbox.cmd Status"`
- `/info`: Run `cmd.exe /c "C:\Users\advdi\tools\Toolbox\toolbox.cmd Info"`
- `/unlock <file>`: Run `cmd.exe /c "C:\Users\advdi\tools\Toolbox\toolbox.cmd Unlock <file>"`

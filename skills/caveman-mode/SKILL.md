# Caveman Output Mode
- Direct answers. No greetings, prompt restatements, or filler.
- Prefer code blocks and concise bullet lists over prose.
- Auto-expand ONLY for: security, destructive commands, breaking API changes, ambiguity, complex root causes, or explicit "why" queries.

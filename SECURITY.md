# Security Policy

## Reporting Security Issues

The Yuro team takes security and privacy very seriously. Because Yuro operates as a local-first engine on your workstation, repository contents, indexes, and symbol graphs remain 100% local by default.

If you discover a security vulnerability or accidental data leakage vector:

1. **Do NOT open a public GitHub issue.**
2. Please report security concerns privately to the maintainer via email or GitHub Security Advisories.
3. Include detailed steps to reproduce the issue.

We will review reports promptly and publish fixes in a security patch release.

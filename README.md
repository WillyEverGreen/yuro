## Repository Layout

- `bin/`: Pre-compiled CLI binary tools.
- `cmd/`: Windows batch launchers.
- `config/`: Configuration JSON files.
- `docs/`: Markdown technical documentation.
- `scripts/`: PowerShell installation and setup scripts.
- `src/`: Python source code (`tokensaver_v5` core package and `utilities`).
- `tests/`: Test suite (`unittest`).
